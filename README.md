# RelicEncoder
Relic Audio Converter

The exe files aifc2fda.exe, dec.exe, enc.exe, fda2aifc.exe, lame.exe, and RAC.exe all come from https://www.moddb.com/games/dawn-of-war/downloads/relic-audio-converter. 

RelicEncode.cpp is inspired by enc.exe; it can convert to both fda and aifc. 

If you are currently using these two formats in your own game, you can use aifc2fda.exe, dec.exe, enc.exe, fda2aifc.exe, lame.exe, and RAC.exe for conversion, 

or you can use the exe compiled from my RelicEncode.cpp for conversion.

Moreover, you can freely convert RelicEncode.cpp into other programming languages to help you reduce development time.
